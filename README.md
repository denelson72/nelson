# Documents Folder

Place PDF files inside these folders:

- `judges-order`
- `evidence`
- `defense-filings`
- `nelson-filings`
- `misc` (can contain nested subfolders)

Example:

```text
src/documents/
  judges-order/
    order-2026-05-01.pdf
  evidence/
    phone-records.pdf
  defense-filings/
    motion-to-dismiss.pdf
  nelson-filings/
    plaintiff-objection.pdf
  misc/
    timeline/
      supporting-doc.pdf
```

Only `.pdf` files are listed automatically on the website.
